# Controls

Connect a controller before launching. The input backend maps supported Xbox and PlayStation controllers to the original DualShock 2 layout. Use **F7** to check button and axis mapping; controller labels can differ from the game's PlayStation prompts.

| PS2 input | Keyboard default |
|---|---|
| Left stick | W / A / S / D |
| Right stick | I / J / K / L |
| D-pad | Arrow keys |
| Cross | X or Space |
| Circle | C |
| Square | Z or keypad 0 |
| Triangle | V or keypad 1 |
| L1 / R1 | Q / E |
| L2 / R2 | Left Shift or 1 / Right Shift or 3 |
| Start | Enter |
| Select | Tab or Backspace |
| L3 / R3 | Left Ctrl / Right Ctrl |

The game's default robot layout uses L1 to jump, R1 for the primary weapon/melee, L2/R2 for Mini-Con slots and Triangle to transform. Follow the game's tutorial for context-dependent actions. Confirm shoulder and trigger mapping with F7 if the wrong weapon fires.

Host shortcuts: **F9** cycles sharpening, **F11** shows speed, **F12** marks a bug and captures a screenshot, **F1** opens settings. Keep captures private until reviewed. See [SETTINGS.md](SETTINGS.md) and [OPTIONS.md](OPTIONS.md) for the current text preset and remapping options. v0.8.3 includes the PC settings menu and `settings.ini`; see SETTINGS.md for precedence.
