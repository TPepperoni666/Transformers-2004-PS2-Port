# Optional locally generated VU1 code

All programs, known-code tables and native packages are derived from your own supported disc and stay outside the checkout. The interpreter remains the default. The recorded 50-image performance package is not distributed or regenerated by these tools; its coverage and compiled-footprint identity are documented research results.

After extracting your ELF, run the commands in [setup](SETUP.md). `tools/vu1/index.py` extracts constant ELF ranges, verifies hashes and creates the detector sidecar. `tools/vu1/package.py` builds a decoder and independent static package using source-only templates. Neither tool needs captures or a recorded package. Both refuse an unsupported ELF; ISO input additionally requires the exact full-disc hash. The disc scanner requires Python 3.11+ and NumPy and emits metadata only.

Static generation currently requires Windows with an MSVC x64 developer shell. Generated code uses the accepted VU scheduler, relocatable guarded multi-pair spans and interpreter fallback. Configure with `PS2X_WITH_VU1_STATIC=ON` and an external `PS2X_VU1_STATIC_DIR`. At runtime use `PS2X_VU1_AOT=1` and `PS2X_VU1_AOT_STATIC=1`. This is opt-in and needs fresh-disc route/hash/visual qualification. It is not the default setup path or a promise of released-package speed.

For separately generated recorded packages, `PS2X_WITH_VU1_AOT=ON` requires an external `PS2X_VU1_AOT_DIR`. No source-tree package is auto-discovered. An absent static package uses declining stubs. Never add generated tables, native code, captures or manifests containing game bytes to the repository.
