# Research Center camp route

`ant_research_camp.tfs` starts from a save with the Research Center warp gate available, enters Antarctica, turns about 45 degrees right and looks over the camp. Create your own save and record a baseline; no memory card is distributed. The stationary `view_start` to `view_end` window spans 900 pad reads (30 seconds of game time). Reference tuple from the private study: vs=7402, pads=3082, cyc=36383043223, cd=1872, i5=3405, mscal=2188294. It only applies to the original undistributed save.

The measured version comparison is in [performance](../../docs/PERFORMANCE.md). Scouting scripts are exploratory, not qualified measurement routes.
